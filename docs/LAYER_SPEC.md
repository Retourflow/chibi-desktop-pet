# 分层清单（LAYER_SPEC）— chibi-desktop-pet v0.1

> 给重画用的规范。按这份清单交付一个分层 PSD，我的代码 rig 会直接按图层名读取。
> 参考图：三视图设定稿（正面为主，侧面 / 背面 / 细节特写作参考）。

## 1. 文件规格

| 项目 | 要求 |
|---|---|
| 格式 | 分层 PSD（Photoshop / Clip Studio / Krita 导出均可） |
| 画布 | 2048 × 2048 px，RGB 8-bit，透明背景 |
| 角色位置 | 水平居中；鹿角顶端约 y=100，靴底约 y=1950 |
| 图层 | **一个部件一个图层**，不要用剪贴蒙版、调整图层、图层效果（导出前合并到该图层本身） |
| 混合模式 | 全部「正常」(Normal)。阴影 / 高光直接画进部件图层 |
| 命名 | 英文 `snake_case`，与下表完全一致。分组名也照抄 |
| 左右 | `_L` / `_R` 指**角色自己的左右**（角色的左 = 画面右侧），和 Live2D 惯例一致 |
| 线稿 | 线稿和上色合在同一部件图层里即可 |

## 2. 最重要的规则：被挡住的地方也要画

代码 rig 转头 ±30° 时，前面的部件会移开，露出后面。**露出来的地方如果没画，就会出现透明的洞。**
下表的「补画」列，就是需要画出平时看不见的部分。
